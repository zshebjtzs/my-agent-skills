# 本质一点通复习

## 使用场景

用户表达以下意图时调用：

- “帮我复习某类知识”
- “一点就通 / 领会本质”
- “还是同样方式”
- “不要编口诀，我只要理解”
- “总结所有最根本的系统”
- “误差分析怎么理解”
- “用简洁通俗的语言理清”

## 核心目标

用最少的话，让用户抓住知识骨架，能自己推具体题。  
不是给结论，而是让用户明白：**这东西到底在干什么。**

## 输出原则

1. **先一句话本质。**  
   开头直接说：这个知识本质就是……

2. **找最小母系统。**  
   能互相表示的合并；不能互相表示的才单列。  
   具体题型都是壳，拆开归到母系统。

3. **如果出现动态变化问题用因果链。**  
   谁变 → 总阻/总流变 → 节点电压变 → 结果变。

4. **出现误差/非理想找等效。**  
   把非理想元件当成电阻，并入或串入理想模型，看等效模型怎么变。

5. **只留核心公式。**  
   每个公式配一句物理意义，不堆公式。

6. **短句、通俗、少术语。**  
   先骨架，后细节。不写长篇推导，除非用户要求。

7. **禁止生成口诀。**  
   不使用押韵、顺口溜、记忆口诀。只用逻辑链和本质句。

8. **主动给易错点、边界、特例。**

9. **最后给自检问题。**  
   让用户知道遇到新题该问哪几句。

## 建议输出模板（实际内容需要根据提示词和上下文动态调整）

1. **一句话本质**
2. **最小母系统 / 基本模型**（不可再分的）
3. **通用分析步骤或链条**
4. **归并表**：具体装置/题型 → 母系统
5. **核心公式**（只留必要，标注含义）
6. **易错点**
7. **遇到新题如何拆解**

## 禁忌

- 不要一上来堆题、堆公式、堆结论。
- 不要把能归并的题型单列。
- 不要用口诀代替理解。
- 不要模糊说“记住就行”。
- 不要长篇推导，除非用户要求。
- 不要生成任何押韵、顺口溜、记忆口诀。

## 输出自检

- 用户看完能否一句话说出本质？
- 能否把新题归到某个母系统？
- 能否自己推出公式和误差方向？
- 是否没有依赖口诀？
- 是否简洁到可以“一点就通”？
